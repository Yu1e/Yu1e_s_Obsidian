# Yu1e_s_Obsidian

Весь код написан разными версиями ИИ Claude.

## Глоссарий

[Глоссарий](https://github.com/Yu1e/Yu1e_s_Obsidian/blob/Dataview/Глоссарий%20(выгрузка%20всех%20подсветок%20в%20хранилище%20в%20список)) - код dataviewjs, который собирает алфавитный список ==подсвеченных== ==фрагментов== из всех заметок хранилища.
Блок кода предназначен для работы внутри заметки, вставляется в отдельную, специально созданную заметку один раз.

## Шаблон для работы с колонками текста

[multicolumn](https://github.com/Yu1e/Yu1e_s_Obsidian/blob/Templates/multicolumn.md) - шаблон Templater, который работает в связке с плагином [Horizontal Blocks](https://github.com/iCodeAlchemy/horizontal-blocks) . Этот шаблон сам распределяет и перераспределяет текст по колонкам.
